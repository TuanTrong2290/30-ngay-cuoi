# Nội dung mới chờ gộp

Dán kết quả từ AI vào đây, mỗi loại một file (chỉ chứa **mục mới**, dạng mảng JSON):

- `customers.json`
- `events.json`
- `rumors.json`
- `zones.json`

Sau đó chạy:

```bash
npm run merge-content
```

Script kiểm tra lỗi trước. Nếu có lỗi thì **không ghi gì cả**, chỉ in ra danh sách lỗi (có thể dán lại cho AI để nó sửa).
